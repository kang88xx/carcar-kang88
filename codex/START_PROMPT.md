# Codex CLI 첫 입력용 프롬프트

이 폴더는 내가 개발할 **가족 공유 아파트 주차 위치 앱**의 기획 및 개발 지침이다.

1. 우선 `AGENTS.md`, `README.md`, `docs/` 전체를 읽어 프로젝트 목표와 제약을 요약해 줘.
2. 현재 PC의 Flutter, Dart, Android SDK, Git 환경을 확인해 줘. Windows 환경이면 iOS 빌드에는 Mac+Xcode가 필요하다는 사실을 구분해 줘.
3. `docs/ROADMAP_AND_QA.md`의 Phase 0부터 진행하고, 각 단계 완료 기준을 지켜 줘.
4. 우선 현재 환경 진단, 개발 폴더 구조, 실행 가능한 최소 Flutter Android 앱 생성 계획, 필요한 계정/환경변수 목록을 보고해 줘.
5. **내 승인 없이 배포, 유료 서비스 가입, 데이터 삭제, 운영 DB 변경, 비밀키 저장을 하지 마.**
6. 초기 서버 비용 월 $0 목표를 지켜. Supabase Free + Flutter, iOS Vision/Android ML Kit의 온디바이스 OCR을 우선해.
7. 모든 차량 데이터는 회원/초대 기반 권한(RLS)을 적용해. 번호판만으로 접근시키지 마.
8. UI는 한국어로 만들고 가족 2~3명이 편하게 쓸 수 있는 빠르고 단순한 구조로 설계해.

먼저 **Phase 0 환경 진단 및 제안**부터 시작해 줘. 곧바로 모든 기능을 한 번에 구현하지 마.
