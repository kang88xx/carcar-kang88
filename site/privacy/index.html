개인정보 처리 안내

차자리는 초대한 가족 사이에서 차량의 마지막 주차 위치와 기록을 공유하는 앱입니다. 아래 안내는 현재 앱의 데이터 처리 방식에 관한 설명입니다.

수집하는 정보와 목적

로그인 이메일과 표시 이름은 인증과 작성자 구분에 사용합니다. 차량 별명·차량번호·아파트 별명, 주차 층·구역·번호·메모, 기록 시각과 작성자는 가족 간 위치 공유와 이력 표시에 사용합니다. 차량번호만으로 다른 가족의 기록에 접근할 수 없습니다.

가족 알림을 켜면 기기 알림 토큰, 기기별 알림 설정과 시간대를 추가로 저장합니다.

사진과 체험 기록

사진의 글자 인식은 기기에서 진행하며 원본 사진을 서버로 업로드하지 않습니다. 촬영 임시 파일은 앱과 운영체제의 캐시 정리 정책을 따릅니다.

체험 모드 기록은 실제 서버와 분리되어 해당 기기에만 저장됩니다. 앱 설정에서 초기화할 수 있습니다.

공유 범위와 보관·삭제

차량에 가입한 가족이 해당 차량의 위치와 이력을 확인합니다. 가족에서 탈퇴하거나 제거되면 해당 차량에 대한 접근이 철회됩니다.

주차 이력은 소유자가 계정을 삭제할 때까지 보관합니다. 소유자 계정 삭제 시 소유 차량과 공유 이력이 삭제됩니다. 다른 차량에 작성한 기록은 작성자 식별을 제거한 상태로 보존됩니다. 계정 삭제는 앱의 설정 → 개인정보와 계정 → 계정 삭제에서 요청할 수 있습니다.

위젯과 알림

위젯 바로 기록을 허용한 기기에는 짧은 수명의 인증 정보를 기기 보안 저장소에 보관합니다. 로그인 갱신용 정보는 위젯과 공유하지 않습니다. 허용을 해제하면 위젯 인증 정보를 삭제합니다.

로그아웃 시 해당 기기의 위젯 스냅샷·인증 정보와 차량 찾기 표시를 지웁니다. 스크린샷이나 다른 기기에 이미 표시된 정보까지 원격 삭제하지는 못합니다.

가족 알림에는 상세 위치·차량번호·이름을 넣지 않습니다. 알림을 끄거나 온라인에서 로그아웃하면 서버의 기기 토큰을 삭제합니다. 오프라인에서는 서버 등록 해제가 완료되지 않을 수 있으며 앱에 안내를 표시합니다. 이미 발송된 알림의 회수는 보장하지 않습니다. 발송 작업은 다음 처리 시 7일 이전 항목을 정리합니다.

사용하는 처리 서비스

Supabase가 인증과 데이터 저장을 처리하며 차자리 데이터베이스는 서울 리전을 사용합니다. 알림 전송에는 Apple APNs와 Google Firebase Cloud Messaging을 사용합니다.

이 웹사이트와 초대 링크

이 사이트는 GitHub Pages에 게시합니다. 사이트 자체에는 광고나 분석 도구를 넣지 않습니다. 웹 호스팅 제공자는 서비스 운영을 위해 접속 정보를 처리할 수 있습니다.

초대 코드는 링크의 # 뒤에 담기며 이 페이지의 스크립트는 코드를 외부 서버로 전송하지 않습니다. 사용자가 앱 열기를 누를 때 설치된 차자리 앱에 전달하고, 복사를 누를 때 기기 클립보드에 복사합니다. 이 페이지에서는 초대의 유효 기간이나 사용 여부를 조회하거나 가족 가입을 처리하지 않습니다.
