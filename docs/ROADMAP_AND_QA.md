# 개발 로드맵 및 QA

이 문서는 초기 단계와 실기기 수용 기준을 보존합니다. 공개 구현·검증 범위는 [README](../README.md#검증)를 확인하세요. 계정별 상세 배포 기록은 비공개로 관리하며 서버 검사의 통과를 실물 두 기기 검증 완료로 표시하지 않습니다.

## 작업 원칙
각 단계는 코드, 테스트, 문서 변경 및 사용자에게 보여줄 검증 방법을 완료한 후 다음 단계로 이동한다. Codex는 보안·비용 정책을 위반하는 자동 외부 서비스 생성/배포를 하지 않는다.

### Phase 0 — 개발 환경과 베이스
- Flutter SDK, Android Studio/SDK, Dart, Git, Codex CLI 확인.
- `flutter doctor -v`와 지원 타깃 확인. Windows의 iOS 빌드 불가 설명.
- Flutter 프로젝트 생성, formatter/analyzer/lints, 환경 변수 템플릿, 라우팅·상태관리 선택 및 이유 기록.
- **완료 기준:** 빈 앱 Android 디버그 실행, analyzer 오류 없음.

### Phase 1 — Auth 및 DB
- Supabase Free 프로젝트 및 로컬 env 템플릿, Google OAuth와 네이티브 복귀 연결. OAuth 비밀키는 서버 설정에만 보관.
- SQL migration 적용 전 보안 리뷰, RLS 정책·테스트 작성.
- **완료 기준:** 로그인 상태 유지/로그아웃, 계정 A/B 간 데이터 차단 자동 테스트.

### Phase 2 — 차량/초대/가족 공유
- 새 차량 등록/받은 초대로 참여(받은 초대는 한 번 탭으로 참여), 등록 시 정규화 번호 중복 거절, 계정당 한 차량 제약, 소유자 생성, 24시간 일회용 링크·코드 초대, 가족 목록.
- 악의적 코드 대입 방지/권한 체크, owner/member 역할.
- **완료 기준:** A가 B 초대, C는 무단 접근 실패.

### Phase 3 — 수동 주차 저장
- 아파트 설정, 층수/구역/번호 입력, 차량 최신 위치/히스토리, Realtime.
- 낙관적 표시와 실제 성공 구분, idempotency, 동시 쓰기 테스트.
- **완료 기준:** 2기기 최신 위치 동일, 네트워크 실패 오표시 없음.

### Phase 4 — 카메라/OCR
- 카메라 권한/촬영, Vision/ML Kit, 결과 파싱 및 확인·수정.
- **완료 기준:** 샘플 30장(빛/각도/한글/영문) 평가, 불확실 결과 수정 후 저장.

### Phase 5 — 홈 화면 위젯
- iOS 네이티브 WidgetKit/App Intents 및 Android widget, Flutter 데이터 연동.
- 현재 선택: 정사각형 모델만 제공. 상단 기록 시각, 큰 층·구역·번호, 앱의 입력 화면을 여는 주차 기록 버튼. 위젯과 아이콘에는 앱 이름을 표시하지 않음. 메인 배너에서 추가 가이드(첫 주차 기록 이후에만 표시).
- **완료 기준:** 앱이 닫혀 있어도 위젯 버튼으로 로그인·차량 확인 후 기존 입력 화면 열기; 사용자 확인 및 서버 확정 저장 후 가족 앱 갱신.

### Phase 6 — 알림 및 Live 표시
- 기기별 설정 저장 및 알림 발송 정책, APNs/FCM 통합.
- iOS ActivityKit '차량 찾기' 수동 시작/종료, 최대 8시간. 얇은 잠금 화면 카드의 표시 종료 버튼과 축약 Dynamic Island 왼쪽 자동차·층수 묶음. 실제 새 기록 시 갱신/재시작 옵션 검토.
- Android 표준 알림 먼저 구현, Now Bar는 기기 테스트 후 도입.
- **완료 기준:** 사용자마다 알림/표시 설정 독립; 권한 OFF/지원 불가 상황 fallback.

### Phase 7 — 릴리스 준비
- 개인정보 처리/보관 및 삭제 정책, 층수 앱 아이콘 11종(F1~F5, B1~B6), 오프라인/복구, 접근성.
- 가족 2~3명 실제 기기 테스트, 배포 자격 요건 및 스토어 제출 준비.

## QA 체크리스트

아래 항목은 릴리스 수용 기준이며 자동 검사와 실제 기기 검증을 구분해 기록한다. 빌드 5의 설치·기존 Live Activity 표시는 사용자 스크린샷으로 확인했다. 최신 Google/초대/아이콘/카드 변경의 전체 실기기 검증 완료를 의미하지 않는다.

- [ ] Google 로그인 취소·재시도·앱 복귀 및 세션 유지
- [ ] 누른 로그인 버튼에만 진행 표시, Google 복귀 뒤 홈 준비 중에는 로그인 화면 대신 진행 표시
- [ ] 로그인된 상태로 앱을 새로 켰을 때 로그인 화면이 스치지 않고 바로 홈(진행 표시)이 보이는지 실기기 확인
- [ ] 로그인 전 받은 초대가 복귀 후 유지되며 `가족 차량에 참여하기`를 누르기 전에는 가입하지 않음. 누르면 코드 입력 시트 없이 참여
- [ ] 초대 저장/삭제 실패를 안내하고 완료로 숨기지 않음
- [ ] 2026-11-11 정리가 든 빌드를 제출하기 전에 `docs/app-store/review-notes.txt`의 등록·초대 단계(차량 번호 중복 확인, 아파트 이름, 가족 초대 코드 만들기, 기존 차량 참여 · 초대코드 입력)와 스토어 스크린샷을 새 화면에 맞춤
- [ ] 계정 전환 시 이전 등록·참여 창 닫힘, 늦은 요청이 새 계정으로 실행되지 않음
- [ ] 차량 번호 중복·형식 오류가 차량 번호 칸 아래에 표시되고 번호를 고치면 사라짐, 동시 등록 충돌 시 서버 거절과 입력 유지
- [ ] 이미 연결된 계정의 다른 차량 등록/참여 거절, 거절 시 초대 사용 횟수 유지
- [ ] 다른 계정으로 차량번호만 입력하면 기존 차량 조회/가입 실패
- [ ] 초대 코드 만료·재사용·대입 제한 동작
- [ ] 만료·재사용 초대는 '이미 사용했거나 24시간이 지난 초대예요…' 안내 후 일반 카드로 복귀
- [ ] 멤버 제거 직후 기록/사진 조회 및 위젯 새 액션 불가
- [ ] A가 B2/C24 저장 → B 앱 최신 데이터 확인
- [ ] A/B 동시 저장 시 최신 포인터와 이력 일관성 유지
- [ ] OCR이 층수를 잘못 읽어도 저장 전 사용자 수정 가능
- [ ] 촬영 권한 거부 시 수동 입력 가능
- [ ] 서버 연결 실패 시 위젯 성공 오표시 없음
- [ ] iOS 소형/Android 2×2 위젯의 상단 기록 시각·긴 위치·기록 없음 및 레이아웃 실기기 확인
- [ ] iOS 소형 위젯 기록 시각 12pt(최소 축소 0.75): 가장 좁은 기기에서 올해 날짜, 작년 날짜('2025년 12월 31일 23:59 기록'), 체험 문구가 시계 아이콘과 한 줄에 잘리지 않고 들어가는지
- [ ] Android 2×2 위젯 기록 시각 12sp: 한 줄/두 줄일 때와 시스템 큰 글자에서 층·구역·번호와 주차 기록 버튼이 눌리거나 잘리지 않는지
- [ ] 위젯 위치 영역→홈, 주차 기록 버튼→입력 화면; 앱 종료/실행 중·로그아웃·계정 전환·중복 탭 확인
- [ ] 홈 배너(첫 주차 기록 이후에만 표시)의 추가 가이드가 열리고 닫기로 홈에 그대로 남는지, 작은 화면·큰 글자 확인
- [ ] iOS 홈에서 빠른 실행 행·최근 기록 목록이 없고 하단 메뉴가 안전 영역을 한 번만 반영하는지 확인
- [ ] iOS 주차 입력의 지상 F1~F5·지하 B1~B5·영문 A~F·한글 가~바가 각각 한 줄로 표시되고 B6·메모·파란 요약 박스가 없는지 확인
- [ ] 서버 migration 적용 후 F·가·바 구역 저장 및 기존 사용자 지정 설정·이력 유지 확인
- [ ] 서버 저장 성공 후 11개 층수 아이콘 반영(Android와 스위치를 켠 iPhone), 실패한 저장은 기존 아이콘 유지
- [ ] iPhone 기본(주차 층수 앱 아이콘 스위치 꺼짐)에서는 저장 뒤 아이콘이 바뀌지 않고 시스템 확인 창도 뜨지 않음
- [ ] 기록 없음·지원 외 층수·로그아웃 시 기본 아이콘, 계정 간 늦은 아이콘 변경 경합 차단
- [ ] iOS 아이콘 시스템 안내는 스위치를 켠 기기에서만 표시, 앱 재활성화 때 가족의 최신 층수 반영
- [ ] iPhone 스위치를 끄면 기본 아이콘으로 복원(시스템 안내 1회), 업데이트 직후 기존 층수 아이콘이 적용돼 있던 기기의 1회 복원
- [ ] 얇은 잠금 화면 카드·왼쪽 자동차/층수 배치, 종료 버튼이 해당 활동만 끝내고 기록은 유지
- [ ] Live Activity 2시간 후 종료, 8시간 초과 활성 시도 없음
- [ ] 새 주차 기록 저장으로 활동 갱신 시 표시 정책 검증
- [ ] 알림 ON 사용자만 수신(작성자 알림 옵션 포함)
- [ ] 앱 재설치·로그아웃·계정 전환 후 기기 토큰 무효화
- [ ] 같은 계정으로 앱을 완전히 껐다 켠 뒤 위젯 위치(비행기 모드로 열었을 때 포함)·차량 찾기 표시(iOS Live Activity는 표시를 눌러 앱을 열어도 유지, Android 고정 알림)·가족 알림(FCM 포함)이 유지되는지
- [ ] 로그아웃 → 다른 계정 로그인 시 이전 계정의 위젯·차량 찾기 표시·알림이 지워지는지
- [ ] 신호 없는 상태로 앱을 새로 켰을 때 '새 차량 등록' 대신 '주차 위치를 불러오지 못했어요' / '다시 시도'가 보이는지
- [ ] 연결이 멈춘 상태(지하 약한 신호)에서 저장 시 15초 뒤 시트가 풀리고, 같은 선택으로 곧바로 재시도해도 이력에 기록이 한 번만 생기는지(iOS·Android)
- [ ] 393pt 폰 실제 계정의 설정 탭에서 '가족 주차 알림' 스위치가 스크롤 없이 보이는지, 알림 묶음이 먼저 오고 '우리 주차장'이 아래로 가는 배치 확인
- [ ] Android 다크 모드: 앱을 새로 켤 때 검은 화면 없이 연한 회청색(#F5F7FA)으로 시작해 번쩍임 없이 이어지는지, 시작 순간 상태 표시줄 아이콘이 밝은 배경 위에서 보이는지
- [ ] Android 12 이상 시작 아이콘 뒤 배경색과 라이트 모드의 시작 화면 → 첫 화면 색 차이, 키보드가 올라올 때 창 배경 확인. 다음 Android 빌드가 `@color/launch_canvas` 참조 오류 없이 통과하는지
- [ ] iOS 실기기(Mac/Xcode 빌드): 시작 화면 배경이 #F5F7FA로 보이는지. iOS가 시작 화면을 캐시하므로 앱을 삭제하고 다시 설치해 확인
- [ ] Supabase 사용량 및 비활성 일시정지 대응 문서화
