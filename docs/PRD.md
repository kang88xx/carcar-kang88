# PRD — 가족 공유 아파트 주차 위치 앱

## 1. 제품 정의
한 대의 차량을 가족 2~3명이 번갈아 사용할 때 차량의 마지막 주차 위치를 공유한다. 초기 버전은 **사용자의 집 아파트 주차장 한 곳**으로 한정한다. 자동 GPS/기압층수 감지는 하지 않는다.

### 성공 지표
- 기존 로그인 사용자의 수동 기록: 3~5번 터치로 저장 가능.
- 사진 OCR 결과는 수정 후 저장할 수 있다.
- 저장한 위치가 다른 구성원의 앱에 신속하게 반영된다(네트워크 연결 시, 실시간 지연은 보장하지 않음).
- 권한 없는 계정이 차량 번호만으로 위치에 접근할 수 없다.

## 2. 핵심 사용 흐름
1. Apple/Google 또는 개발 단계에서 지원하는 Supabase Auth 방식으로 로그인.
2. 아파트 이름(별칭), 차량 번호, 차량 별칭 등록 → 내부 UUID `vehicle_id` 발급.
3. 소유자가 만료형 일회용/제한횟수 초대 코드를 생성 → 가족이 입력해 차량 참여.
4. 주차자가 앱 수동 입력 또는 카메라 OCR로 `층수`, `구역`, `번호(선택)`를 확인 후 저장.
5. 서버에 주차 기록을 추가하고 최신 위치 포인터를 갱신. 다른 가족의 앱/위젯은 최신 상태 조회 및 갱신.
6. 이용자별 설정에 따라 알림과 상단 표시 사용. 두 기능은 독립 설정.

## 3. MVP 범위
### 필수 P0
- 인증 세션 유지, 로그아웃, 계정별 프로필.
- 차량 등록/별칭/번호(공유 초대 없이 제3자 접근 불가).
- 차량 소유자 초대 코드 생성·만료·참여, 구성원 목록 및 내보내기.
- 동일 `vehicle_id` 소속 여러 사용자 간 최신 주차 위치 공유.
- 직접 선택: 층수(B1~B4 예시, 아파트별 설정), 구역(A~E 예시), 번호 선택 입력, 사진 메모 선택.
- 원본 주차 이력 보관, 최신 주차 상태 표시, 기록자 및 시각 표시.
- 카메라로 기둥/표지판 촬영 → 온디바이스 OCR → 필드 제안 → 사용자 확인·수정 후 저장.
- 인터랙티브 위젯: 현재 위치 확인; 지원되는 크기에서 층수/구역 선택 및 저장. UI 공간 부족 시 상세 입력은 앱의 딥링크로 이동.
- 차량 아이콘 8종 중 선택: 앱 내부에서는 구성원 모두 동일. iOS 앱 런처 아이콘은 개별 기기에서 사용자 동의하에 별도 적용.
- 사용자/기기별 `push_enabled`, `live_enabled`, `notify_own`, `quiet_hours` 설정.
- RLS 및 초대 코드 보안, 오류 및 재시도 처리.

### P1 (P0 안정화 이후)
- iOS Live Activity: '차량 찾기 모드'를 사용자가 켜고 끄기, 1/2/4/8시간 이내 설정, 저장된 기존 주차 위치 표시.
- 새 실제 주차 기록 저장 시 이전 활동 종료→새 활동 시작 옵션(시스템 허용 및 사용자 의도 전제). 단순 레코드 수정은 자동으로 8시간 리셋하지 않음.
- Android 알림 및 지원 가능한 Live Updates/Now Bar 연동(기종별 지원 확인).
- 원본 사진의 선택적 암호화/비공개 저장, 사진 자동 정리.

### 제외
- GPS/기압 자동 층수 인식, 내비게이션, 외부 주차장 검색.
- AI 서버 OCR, 유료 지도 API, SMS 인증 필수화, AWS 상시 서버.
- 영구 Dynamic Island 표시 및 강제 상단 고정.

## 4. 화면 목록
1. 온보딩/로그인
2. 홈: 차량 선택, 최신 층·구역·번호, 기록자/시간, '주차 기록', '차량 찾기 표시'
3. 주차 기록: 수동 탭 / 카메라 탭, 제안값 수정, 최종 확인, 저장 상태
4. 차량/가족: 차량명, 번호, 구성원, 초대코드, 탈퇴/제거
5. 차량 아이콘: 아이콘 그리드, 앱 내부 공유 설정, 별도 런처 아이콘 적용
6. 이력: 최신 우선 기록 조회
7. 설정: 기기별 알림, Live Activity ON/OFF, 시간, 내 기록 알림, 야간 설정, 로그아웃

## 5. 위젯 동작
- 소형: 마지막 위치 표시 + 탭하여 앱 열기.
- 중형: 층수 선택 등 제한된 인터랙션. 플랫폼별 실제 여유 공간과 동작 검증 후 기능 확정.
- 저장 버튼 탭: 인증된 사용자/차량 컨텍스트 확인 → 서버 기록 → 성공/실패 피드백 → 로컬 위젯 스냅샷 갱신.
- 앱이 실행되지 않아도 저장 가능하도록 네이티브 위젯 액션을 구현한다. 기기 보안 토큰과 세션 접근은 플랫폼별 보안 검토.
- 가족의 타 기기 위젯 갱신은 즉시 보장되지 않는다. 앱 활성화·시스템 허용 갱신 시 최신 위치 재조회.

## 6. 기록 규칙
- `floor`: 아파트별 허용값 목록 중 선택. 예: `B1`, `B2`, `B3`, `B4`.
- `zone`: 허용값 목록 중 선택. 예: `A`~`E`.
- `spot`: 0~20자, 선택값. OCR 텍스트가 불확실하면 빈 값.
- `created_at`: 서버 기준 UTC. 화면에서는 기기 로컬 시간.
- 주차 저장은 원자적으로 `parking_records`에 insert + `vehicles.latest_parking_record_id` 갱신.
- 동시에 여러 가족이 저장한 경우 DB가 확정한 마지막 기록을 현재 주차 위치로 사용. 기록 전체 이력은 보존.
- 사진 OCR만으로 자동 저장하지 않는다. 반드시 확인 버튼을 거친다.
- 출차는 MVP에서는 선택적 '주차 종료' 상태로 추후 확장 가능.

## 7. 수용 기준
- 가족 A가 기록하면 B가 앱 새로고침/실시간 갱신으로 동일 위치를 확인.
- 외부 계정 C는 번호판만 알아도 차량/위치/사진을 조회하지 못함.
- OCR이 `B8`을 `B3`으로 오인해도 사람이 수정 가능.
- 위젯 저장 실패 시 성공한 것처럼 표시하지 않음.
- 아이콘 공유 변경은 앱 내부 즉시 조회 가능; iOS 홈 화면은 사용자가 별도 적용.
- 상단 표시가 꺼져 있어도 주차 기록과 공유가 정상 작동.
