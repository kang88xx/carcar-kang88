# PRD — 가족 공유 아파트 주차 위치 앱

## 1. 제품 정의
한 대의 차량을 가족 2~3명이 번갈아 사용할 때 차량의 마지막 주차 위치를 공유한다. 한 계정은 **차량 한 대**에만 연결하며, 초기 버전은 **사용자의 집 아파트 주차장 한 곳**으로 한정한다. 자동 GPS/기압층수 감지는 하지 않는다.

### 성공 지표
- 기존 로그인 사용자의 수동 기록: 3~5번 터치로 저장 가능.
- 사진 OCR 결과는 수정 후 저장할 수 있다.
- 저장한 위치가 다른 구성원의 앱에 신속하게 반영된다(네트워크 연결 시, 실시간 지연은 보장하지 않음).
- 권한 없는 계정이 차량 번호만으로 위치에 접근할 수 없다.

## 2. 핵심 사용 흐름
1. Google로 로그인. 가입 없는 체험은 해당 기기의 로컬 데이터로만 제공.
2. **새 차량 등록** 또는 **기존 차량 참여** 선택. 새 차량은 번호 중복 확인 후 아파트 이름(별칭), 차량 별칭, 내 이름과 함께 등록 → 내부 UUID `vehicle_id` 발급.
3. 최초 등록 소유자가 링크 또는 코드를 공유. 가족은 로그인 후 24시간 유효한 일회용 초대를 명시적으로 확인해 참여. 차량번호만으로 참여할 수 없으며 한 계정에 두 차량을 연결하지 않음.
4. 주차자가 앱 수동 입력 또는 카메라 OCR로 `층수`, `구역`, `번호(선택)`를 확인 후 저장.
5. 서버에 주차 기록을 추가하고 최신 위치 포인터를 갱신. 다른 가족의 앱/위젯은 최신 상태 조회 및 갱신.
6. 이용자별 설정에 따라 알림과 상단 표시 사용. 두 기능은 독립 설정.

## 3. MVP 범위
### 필수 P0
- 인증 세션 유지, 로그아웃, 계정별 프로필.
- 계정당 차량 한 대: 정규화한 차량번호 중복 확인 및 서버 고유 제약, 별칭/번호 표시. 번호 중복 확인은 소유권 인증이나 접근 권한 부여가 아님.
- 차량 소유자만 48자리 hex 초대 생성·공유. 24시간 만료·1회 사용, 링크/코드 입력 후 참여 확인, 구성원 목록 및 내보내기.
- 동일 `vehicle_id` 소속 여러 사용자 간 최신 주차 위치 공유.
- 직접 선택: 지상 F1~F5와 지하 B1~B5를 제목으로 구분해 각각 한 줄로 표시. 구역은 A~F와 가~바를 각각 한 줄로 표시하며 번호는 선택 입력. 새 주차 입력에서는 메모와 별도 위치 요약 박스를 제공하지 않는다.
- 원본 주차 이력 보관, 최신 주차 상태 표시, 기록자 및 시각 표시.
- 카메라로 기둥/표지판 촬영 → 온디바이스 OCR → 필드 제안 → 사용자 확인·수정 후 저장.
- 정사각형 위젯: 상단 기록 시각, 큰 층수와 구역·번호, 하단 주차 기록 버튼. 버튼은 앱의 기존 입력 화면을 열며 직접 저장하지 않는다. iOS 소형 및 Android 2×2 모델 한 종류를 제공한다.
- 앱 아이콘은 서버가 확정한 현재 주차 층수에 따라 자동 변경: F1~F5 및 B1~B6의 11종. 기록 없음·지원하지 않는 층수·로그아웃 시 기본 아이콘. 수동 색상 선택 UI는 제공하지 않음.
- iOS 아이콘 변경에는 시스템 안내가 나타날 수 있음. 앱이 닫힌 동안 가족이 변경한 위치는 다음 실행/활성화 때 반영하며, 백그라운드에서 즉시 아이콘이 바뀐다고 보장하지 않음.
- 메인 위젯 안내 배너에서 추가 방법을 확인하고 앱 내부 위젯 설정으로 바로 이동.
- 사용자/기기별 `push_enabled`, `live_enabled`, `notify_own`, `quiet_hours` 설정.
- RLS 및 초대 코드 보안, 오류 및 재시도 처리.

### P1 (P0 안정화 이후)
- iOS Live Activity: '차량 찾기 모드'를 사용자가 켜고 끄기, 1/2/4/8시간 이내 설정, 저장된 기존 주차 위치 표시. 잠금 화면은 얇은 두 줄 카드와 표시 종료 버튼, Dynamic Island 축약형은 왼쪽에 자동차·층수를 나란히 표시. 종료는 해당 활동 표시만 끝내며 주차 기록을 삭제하지 않음.
- 새 실제 주차 기록 저장 시 이전 활동 종료→새 활동 시작 옵션(시스템 허용 및 사용자 의도 전제). 단순 레코드 수정은 자동으로 8시간 리셋하지 않음.
- Android 알림 및 지원 가능한 Live Updates/Now Bar 연동(기종별 지원 확인).
- 원본 사진의 선택적 암호화/비공개 저장, 사진 자동 정리.

### 제외
- GPS/기압 자동 층수 인식, 내비게이션, 외부 주차장 검색.
- AI 서버 OCR, 유료 지도 API, SMS 인증 필수화, AWS 상시 서버.
- 영구 Dynamic Island 표시 및 강제 상단 고정.

## 4. 화면 목록
1. 온보딩/로그인
2. 홈: 연결된 차량 한 대, 최신 층·구역·번호, 기록자/시간, '주차 기록', 위젯 안내 배너. 네 개의 빠른 실행 버튼과 최근 이력 목록은 제거하고, 이력은 하단 '주차 이력'에서 확인.
3. 주차 기록: 수동 탭 / 카메라 탭, 제안값 수정, 최종 확인, 저장 상태
4. 차량/가족: 차량명, 번호, 구성원, 초대코드, 탈퇴/제거
5. 앱 아이콘 안내: 층수에 따른 자동 변경 설명과 실패 시 다시 맞추기
6. 이력: 최신 우선 기록 조회
7. 설정: 기기별 알림, Live Activity ON/OFF, 시간, 내 기록 알림, 야간 설정, 로그아웃

## 5. 위젯 동작
- 홈 화면 배치는 사용자가 운영체제의 위젯 추가 화면에서 직접 수행. 안내 배너의 바로 가기는 **앱 내부 위젯 설정**으로 이동하며 iOS 위젯 갤러리 자동 열기나 자동 배치를 약속하지 않음.
- 정사각형 모델만 제공: iOS systemSmall, Android 2×2 기본 크기. Android 외곽 비율은 런처별 셀 규격에 좌우된다.
- 상단 시각은 주차 기록의 저장 시각이며 화면 갱신 시각이 아니다. 기기 로컬 시간으로 표시하고 다른 연도는 연도를 포함한다.
- 위치 영역은 홈, 주차 기록 버튼은 앱의 입력 화면으로 이동한다. 앱이 닫혀 있으면 실행한 뒤 로그인·차량 연결 상태를 확인하고 입력을 연다.
- 사용자가 앱에서 확인 후 저장해야 서버 기록 → 성공/실패 피드백 → 로컬 위젯 스냅샷 갱신이 진행된다. 이전 네이티브 저장 액션은 호환용으로 유지하며 새 위젯에서는 호출하지 않는다.
- 가족의 타 기기 위젯 갱신은 즉시 보장되지 않는다. 앱 활성화·시스템 허용 갱신 시 최신 위치 재조회.

## 6. 기록 규칙
- `floor`: 아파트별 허용값 목록 중 선택. 기본값: `F1`~`F5`, `B1`~`B5`. 새 입력에서 B6는 제외하고 기존 B6 기록은 보존한다.
- `zone`: 허용값 목록 중 선택. 기본값: `A`~`F`, `가`, `나`, `다`, `라`, `마`, `바`. 사용자 지정 구역명은 읽을 수 있는 너비로 표시한다.
- `spot`: 0~20자, 선택값. OCR 텍스트가 불확실하면 빈 값.
- `note`: 기존 메모는 이력과 최신 위치에서 보존·표시하며 새 입력은 빈 값으로 저장한다.
- `created_at`: 서버 기준 UTC. 화면에서는 기기 로컬 시간.
- 주차 저장은 원자적으로 `parking_records`에 insert + `vehicles.latest_parking_record_id` 갱신.
- 동시에 여러 가족이 저장한 경우 DB가 확정한 마지막 기록을 현재 주차 위치로 사용. 기록 전체 이력은 보존.
- 사진 OCR만으로 자동 저장하지 않는다. 반드시 확인 버튼을 거친다.
- 출차는 MVP에서는 선택적 '주차 종료' 상태로 추후 확장 가능.

## 7. 수용 기준
- 가족 A가 기록하면 B가 앱 새로고침/실시간 갱신으로 동일 위치를 확인.
- 외부 계정 C는 번호판만 알아도 차량/위치/사진을 조회하지 못함.
- OCR이 `B8`을 `B3`으로 오인해도 사람이 수정 가능.
- 위젯 저장 실패 시 성공한 것처럼 표시하지 않음.
- 저장 실패 시 앱 아이콘은 이전 층수 유지. 서버 확정 후 기기 아이콘 갱신 실패는 주차 저장 성공을 취소하지 않으며 재시도 안내.
- 다른 계정으로 전환하면 이전 등록·참여 창과 늦게 도착한 응답이 새 계정에 영향을 주지 않음.
- 초대 링크로 앱을 열어도 자동 가입하지 않으며 로그인 왕복 뒤 받은 초대를 유지.
- 상단 표시가 꺼져 있어도 주차 기록과 공유가 정상 작동.
