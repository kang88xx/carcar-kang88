# 결정 로그

## 확정
- 첫 사용 장소: 자기 집 아파트 주차장 한 곳.
- 기록은 수동. 앱 내 카메라 OCR은 **자동 입력 제안**, 저장은 사용자 확인.
- 가족 2~3명이 차량 한 대의 주차 위치를 공유하며 한 계정은 한 차량에만 연결.
- 앱/위젯 모두 기록 가능; 사용자별 푸시/상단 표시 설정 독립.
- iOS Live Activity 제한 8시간은 등록/로그인/주차 기록이 아니라 **활동 시작 시점**부터.
- 월 서버비 $0 목표, Supabase Free, 기기 내 OCR, 유료 API 피함.
- iOS 및 Android 모두 고려: Flutter + 플랫폼 네이티브 확장.
- iOS 최소 지원은 15.0. 빌드 4의 Apple `ITMS-90068` 안내에 따라 Podfile·Flutter framework·프로젝트 설정을 맞추며, 컴파일된 앱의 최소 버전을 업로드 전에 검사. 위젯·차량 찾기는 기존 iOS 17 이상 조건 유지.

## 현재 제품 기본값 · 2026-11-02
- 첫 아파트 층수: F5/F4/F3/F2/F1/B1/B2/B3/B4/B5/B6 (설정에서 변경 가능)
- 기본 구역: A/B/C/D/E (설정에서 변경 가능)
- 번호: 선택 입력, 최대 20자
- 차량 수: 계정당 한 대. 최초 등록자는 소유자, 다른 가족은 소유자의 초대로만 참여. 정규화 차량번호는 DB에서 고유함
- 초대 코드: 192비트 난수의 48자리 hex, 24시간 유효, 1회 사용. 링크와 코드 공유를 제공하되 자동 가입하지 않음
- 사진 서버 저장: 기본 OFF (OCR 후 원본 기기에서만 처리)
- 실시간 표시: 기본 OFF, 명시적 사용자 활성화
- 본인 주차 기록 알림: 기본 OFF
- 야간 알림 제한: 기본 OFF
- 사용자 표기 시간대: 기기 로컬

## 주의할 미확정 사항
- 실제 아파트 기둥 표기의 형식(B2+C24가 한 사진에 나오는지).
- 실기기 Android Now Bar 지원 모델/OS 조합.
- Google OAuth의 실제 로그인 왕복, 가족 간 공유·푸시, 최신 네이티브 변경의 실기기 검증은 릴리스마다 확인. 플랫폼 설정 완료나 App Store 심사 통과를 코드 구현만으로 확정하지 않음.
- 공개 App Store 배포 전에 소셜 로그인 관련 심사 요건과 Apple 로그인 추가 필요성을 검토. 현재 Google 로그인 구현을 공개 배포 승인으로 간주하지 않음.

## 변경 이력 · 2026-11-02

- 초기 이메일/비밀번호 가입 화면을 Google 로그인으로 대체. 기존 계정의 복구 링크 처리만 호환 경로로 남김. 새 가입 흐름에 SMTP나 문자 인증을 요구하지 않음.
- 초기 DB 다중 차량 허용안을 폐기하고 계정당 차량 한 대로 제한. 번호 중복 확인 결과에는 소유자 정보가 없으며 번호가 가입 권한이 되지 않음.
- 기존 공유 색상 선택·기기별 수동 8색 런처 아이콘을 자동 층수 아이콘 11종(F1~F5, B1~B6)으로 대체. 이전 자산/필드는 호환용 보존. 서버 확정 기록에 맞춰 활성 기기에서 갱신하며 iOS 시스템 안내를 숨기지 않음. 앱이 닫힌 기기의 즉시 변경은 보장하지 않음.
- 잠금 화면 차량 찾기 카드를 얇게 줄이고 표시 종료 버튼을 추가. Dynamic Island 축약형 왼쪽에 자동차와 층수를 묶음. 표시 종료와 주차 기록 삭제를 분리.
- 홈 화면에 위젯 추가 가이드 배너와 앱 내부 설정 바로 가기 제공. OS의 위젯 자동 추가/갤러리 직접 이동 기능으로 표현하지 않음.
- TestFlight 빌드 5의 실제 설치·기존 Live Activity 표시는 사용자 스크린샷으로 확인. 이후 변경의 배포·실기기 검증은 별도 결과로 기록.
