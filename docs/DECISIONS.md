## 하단 메뉴·입력창 간격 재점검 · 2026-11-06

- 320px·글자 1.3배 화면에서 하단 탭 글자가 밀집하고 주차 저장 영역이 큰 점을 수정했다. 공통 메뉴의 좌우 여백은 12px, 아이콘은 22px, 라벨은 11px·행높이 1.2로 정리했다. 72px 메뉴 높이와 안전 영역 1회 적용, 네 탭의 이름·기능은 유지한다.
- 주차 입력의 제목·선택 글자 크기를 14/15px로 구분하고 간격을 줄였다. 저장 문구는 `주차 기록 저장` / `체험 기록 저장`으로 간결하게 바꾸고, 설명문과 고정 저장 영역의 여백도 줄였다. 공통 설정창의 좌우 제목 여백과 하단 여백을 맞췄다.
- 이전 PNG의 단단한 회색 이중 그림자는 Flutter 테스트가 블러를 끈 영향이었다. 캡처할 때만 실제 그림자를 활성화하고 종료 시 복원한다. 앱의 그림자도 더 옅게 조정했다.
- 새 갤러리는 `docs/qa/ios-footer-review/`이며 네 탭과 입력·설정창을 포함한다. 작은 화면에서 실제 폰트의 글자 경계·간격과 탭 이동을 검사한다. 캡처와 iOS 실기기 검증은 구분한다.

## iOS 홈·주차 입력 정리 · 2026-11-06

- iPhone 화면 피드백에 따라 하단 내비게이션의 안전 영역 중복을 제거했다. 홈의 사진 기록·차량 찾기·이력 보기·위젯 빠른 실행 행과 최근 주차 기록 목록을 삭제하고 위젯 안내 배너는 유지한다. 이력은 하단 메뉴에서 확인한다.
- 주차 입력은 지상 F1~F5, 지하 B1~B5를 각각 한 줄로 구분한다. B6 선택은 제거한다. 영문 A~F와 한글 가~바 구역도 각각 한 줄로 배치하며 사용자 지정 이름은 넓은 행을 사용한다.
- 가족 메모 입력과 저장 버튼 위의 파란 위치 요약 박스를 제거했다. 기존 기록·메모·B6 이력과 호환용 층수 아이콘은 보존한다.
- `20261106034310_parking_option_defaults.sql`은 새 아파트의 기본값과 정확히 일치하는 이전 기본값 배열만 바꾼다. 사용자 지정 설정·이력·RLS·저장 RPC는 유지한다. 실제 계정에 새 기본 구역을 제공하려면 서버에도 이 migration이 필요하며, 이번 작업에서는 원격 DB에 적용하지 않았다.
- 검증은 iOS 배치에 집중한다. Flutter의 iOS 테마·안전 영역으로 작은 화면과 큰 글자를 렌더링하고, Mac용 네이티브 테스트에 동일한 행 배치 검사를 추가했다. Windows/WSL에서 Xcode·iOS 실기기 실행을 완료한 것으로 간주하지 않는다. Android 실기기 검증은 이후 진행한다.

## 정사각형 위젯 시안 확정 · 2026-11-06

- 사용자는 정사각형 모델만 사용하기로 했고, 시간 표시를 수정한 두 번째 시안 묶음의 **1번(상단 기록 시각)**을 선택했다. 기준 이미지는 `docs/design/square-widget-time-variants-2026-11-06/01-top-caption.png`다. 첫 시안 묶음의 1번과 구분한다.
- 상단 시계 아이콘과 `11월 6일 18:42 기록`, 가운데 큰 층수 및 구역·번호, 하단 `주차 기록` 버튼을 사용한다. `updatedAt` 스냅샷 값은 서버 주차 기록의 `created_at`이므로 ‘갱신’으로 표현하지 않는다. 다른 연도의 기록은 연도도 표시한다.
- iOS는 소형만 제공하고 Android는 2×2 기본 크기 한 종류로 제공한다. Android의 실제 외곽 비율은 런처 셀 규격에 좌우된다.
- `주차 기록`은 `carcar://parking`으로 앱의 기존 입력 화면을 연다. 위치 영역은 홈을 연다. 위젯에서 직접 저장하지 않으며 사용자 확인 및 서버 저장 확정 절차는 유지한다. 로그인·차량 연결이 준비되지 않았을 때 입력을 우회하지 않는다.
- 이전 위젯에서 사용하던 서버 저장 코드와 보안 검사는 호환용으로 유지한다. 새 화면에서 직접 저장 권한을 켜는 UI는 없고, 기존 허용 사용자의 해제 경로는 유지한다.
- 소스 적용은 앱 배포나 실기기 검증 완료를 뜻하지 않는다. iOS 빌드·소형 위젯 탭·배치 검증은 Mac/Xcode에서 진행한다. 설치된 중형·대형 위젯은 새 빌드에서 소형으로 다시 추가해야 할 수 있다.


## 작업 저장 및 다음 세션 인계 · 2026-11-04

- 현재 배포는 **TestFlight 1.0.0 (10)**이다. 블루·슬레이트 UI와 네이티브 아이콘·위젯, 설치 표시명 **차자리**, 스토어 등록명 **차자리 - 가족 주차 기록**을 반영했다. Apple 처리와 내부 테스트 그룹 연결을 확인했다.
- 앱 변경 소스는 `09dd1a1`, 표시명 확인 도구와 결정 기록까지 포함한 소스는 `f6042da`다. Flutter 153개·브라우저 12개·Node 38개 검사 및 공개 CI가 통과했다. 배포 상세와 계정별 증거는 로컬 `docs/RELEASE_STATUS.md`, `docs/qa/blue-refresh/`에 보존한다.
- 사용자가 줄이고 싶은 위젯은 **아이폰 홈 화면의 주차 위젯**이다. 현재 빌드에서 소형·중형·대형을 이미 지원한다. 소형은 위치 확인용이며 중형·대형은 층·구역 선택과 등록 기능을 제공한다. 이번 문의로 코드를 변경하거나 새 빌드를 배포하지 않았다.
- 홈 화면 위젯의 외곽 크기는 iOS의 WidgetFamily 규격을 따른다. 여백·글자 크기를 줄여도 홈 화면 점유 공간은 줄어들지 않는다. 소형에서 등록 버튼을 생략한 것은 현재 앱의 설계이며, iOS가 소형의 모든 상호작용을 금지하는 것은 아니다. [Apple 위젯 규격](https://developer.apple.com/design/human-interface-guidelines/widgets), [위젯 추가 방법](https://support.apple.com/en-us/118610).
- 스크린샷 기능의 Supabase/Hugging Face 대안은 가능성과 비용을 설명한 상태다. 화면 캡처인지 사진 OCR인지 대상은 미확정이며, 외부 서비스 도입이나 사진 업로드 변경은 없다. 현재 로컬 Playwright와 기기 내 OCR을 유지한다.
- 빌드 10의 실제 iPhone 설치와 카메라·푸시·위젯·Live Activity 동작 확인은 남아 있다. 현재 구현·배포 작업은 마쳤으며 사용자의 다음 요청부터 이어간다.

## 아이콘·위젯에서 앱 이름 제거, 위젯 층 버튼 직접 선택 · 2026-11-03

- 층수 앱 아이콘 11종에서 하단의 앱 이름 글자를 제거하고 층 라벨만 크게 가운데 배치한다. 런처가 이미 앱 이름을 보여 주므로 중복 표기를 하지 않는다. `assets/launcher/generate_floor_icons.py`로 재생성했다.
- 홈 화면 위젯은 제목 줄(앱 이름)을 없애고 위치를 헤드라인으로 둔다. 배경은 짙은 잉크색, 글자는 흰색, 선택 상태와 등록 버튼은 라임색으로 가시성을 높였다.
- 위젯의 층 선택은 '다음 층' 순환 버튼 대신 설정된 층 버튼(최대 12개, 6개씩 두 줄)을 직접 누르는 방식으로 바꿨다. 선택 후 **등록**을 눌러야 서버에 저장하며, 서버 확인 전에는 성공을 표시하지 않는다. 구역은 기존 순환 버튼을 유지한다. 13개 이상 층을 설정한 경우 나머지 층은 앱에서 기록한다.
- Android 위젯 기본 크기를 4×3으로 올리고(최소 250×180dp), 너비 200dp·높이 140dp 미만으로 줄이면 조작부를 숨기고 위치만 표시한다. iOS는 small·medium·large를 지원하며 small은 위치만 표시한다.
- 참고 UI(Mobbin Future Pro) 기반의 앱 화면 전체 재설계는 이 변경에 포함하지 않았다. Mobbin MCP가 세션에 로드된 뒤 별도로 진행한다.

## 확정
- 첫 사용 장소: 자기 집 아파트 주차장 한 곳.
- 기록은 수동. 앱 내 카메라 OCR은 **자동 입력 제안**, 저장은 사용자 확인.
- 가족 2~3명이 차량 한 대의 주차 위치를 공유하며 한 계정은 한 차량에만 연결.
- 앱/위젯 모두 기록 가능; 사용자별 푸시/상단 표시 설정 독립.
- iOS Live Activity 제한 8시간은 등록/로그인/주차 기록이 아니라 **활동 시작 시점**부터.
- 월 서버비 $0 목표, Supabase Free, 기기 내 OCR, 유료 API 피함.
- iOS 및 Android 모두 고려: Flutter + 플랫폼 네이티브 확장.
- iOS 최소 지원은 15.0. 빌드 4의 Apple `ITMS-90068` 안내에 따라 Podfile·Flutter framework·프로젝트 설정을 맞추며, 컴파일된 앱의 최소 버전을 업로드 전에 검사. 위젯·차량 찾기는 기존 iOS 17 이상 조건 유지.

- 실기기 Android Now Bar 지원 모델/OS 조합.
- Google OAuth의 실제 로그인 왕복, 가족 간 공유·푸시, 최신 네이티브 변경의 실기기 검증은 릴리스마다 확인. 플랫폼 설정 완료나 App Store 심사 통과를 코드 구현만으로 확정하지 않음.
- 공개 App Store 배포 전에 소셜 로그인 관련 심사 요건과 Apple 로그인 추가 필요성을 검토. 현재 Google 로그인 구현을 공개 배포 승인으로 간주하지 않음.

## 변경 이력 · 2026-11-02

- 초기 이메일/비밀번호 가입 화면을 Google 로그인으로 대체. 기존 계정의 복구 링크 처리만 호환 경로로 남김. 새 가입 흐름에 SMTP나 문자 인증을 요구하지 않음.
- 초기 DB 다중 차량 허용안을 폐기하고 계정당 차량 한 대로 제한. 번호 중복 확인 결과에는 소유자 정보가 없으며 번호가 가입 권한이 되지 않음.
- 기존 공유 색상 선택·기기별 수동 8색 런처 아이콘을 자동 층수 아이콘 11종(F1~F5, B1~B6)으로 대체. 이전 자산/필드는 호환용 보존. 서버 확정 기록에 맞춰 활성 기기에서 갱신하며 iOS 시스템 안내를 숨기지 않음. 앱이 닫힌 기기의 즉시 변경은 보장하지 않음.
- 잠금 화면 차량 찾기 카드를 얇게 줄이고 표시 종료 버튼을 추가. Dynamic Island 축약형 왼쪽에 자동차와 층수를 묶음. 표시 종료와 주차 기록 삭제를 분리.
- 홈 화면에 위젯 추가 가이드 배너와 앱 내부 설정 바로 가기 제공. OS의 위젯 자동 추가/갤러리 직접 이동 기능으로 표현하지 않음.
- TestFlight 빌드 5의 실제 설치·기존 Live Activity 표시는 사용자 스크린샷으로 확인. 이후 변경의 배포·실기기 검증은 별도 결과로 기록.
