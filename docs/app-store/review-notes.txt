차자리 / Chajari — App Review access instructions
Build: 1.0.0 (13). The interface is Korean.

[한국어]
차자리는 차량 한 대의 주차 위치를 초대한 가족과 공유하는 앱입니다. 인터넷 연결이 필요합니다. 첫 화면의 ‘Apple로 계속하기’ 또는 ‘Google로 계속하기’로 심사에 사용할 Apple/Google 계정에 로그인하면 앱 계정이 생성됩니다. 별도의 차자리 이메일/비밀번호 로그인, SMS 인증, 유료 가입은 없습니다.

1. 첫 계정: ‘새 차량 등록’을 선택해 ‘차량 별명’, ‘차량 번호’, ‘아파트 이름’, ‘내 이름’을 입력합니다. 차량 번호는 화면 예시의 한국 번호 형식을 따르고 ‘차량 번호 중복 확인’ 후 ‘차량 등록하기’를 누릅니다. 이미 사용 중인 번호는 다른 차량으로 등록할 수 없습니다. 심사용 비민감 데이터를 사용해 주세요. 계정당 차량 한 대만 연결됩니다.
2. 홈의 ‘주차 기록하기’에서 층·구역을 선택하고 선택 사항인 주차 번호를 입력한 다음 ‘주차 기록 저장’을 누릅니다. 서버 저장 완료 후 홈과 이력에서 확인합니다. ‘표지판 촬영’ 또는 ‘앨범에서 선택’으로 기기 내 OCR을 사용할 수 있으며, 인식한 후보를 확인·수정한 뒤 저장합니다.
3. 가족 공유: 첫 계정의 ‘우리 가족’에서 ‘가족 초대 코드 만들기’를 선택하고 ‘코드 복사’ 또는 ‘초대 링크 공유’를 사용합니다. 두 번째 기기의 다른 Apple/Google 계정으로 로그인한 뒤 ‘기존 차량 참여 · 초대코드 입력’에 코드를 넣고 ‘가족 차량에 참여하기’를 누릅니다. 두 번째 계정은 새 차량을 등록하지 않아야 합니다. 코드는 24시간 동안 한 번만 사용 가능하며 필요하면 소유자가 새 코드를 만듭니다. 두 계정에서 같은 차량의 위치·이력을 확인할 수 있습니다.
4. 계정 삭제: ‘설정’ → ‘개인정보와 계정’ → ‘계정 삭제’. 확인 후 소유 차량과 공유 기록도 삭제됩니다. Apple 계정은 연결 해제를 위해 다시 인증하며, 자동 해제가 불가능하면 안내를 확인한 뒤 수동 Apple 연결 해제 경로를 선택할 수 있습니다. 삭제는 마지막에 시험해 주세요.

‘체험 시작하기’는 로그인 없이 로컬 화면·기록을 살펴보는 기능입니다. 실제 서버 저장, 가족 간 동기화, 서버 초대·계정 삭제를 제공하는 심사용 계정의 대체 경로가 아닙니다. 이 기능들은 위 로그인·초대 절차로 접근합니다.

[English]
Chajari shares one vehicle's last parking location with invited family members. An internet connection is required. On the first screen, choose ‘Apple로 계속하기’ (Continue with Apple) or ‘Google로 계속하기’ (Continue with Google), using an Apple/Google account available for review. First sign-in creates the app account. There is no separate Chajari email/password sign-in, SMS verification, or paid subscription.

1. Owner setup: choose ‘새 차량 등록’ (Register a new vehicle). Enter vehicle nickname, vehicle number, apartment name, and your display name. Follow the Korean vehicle-number format shown in the field, tap ‘차량 번호 중복 확인’ (Check availability), then ‘차량 등록하기’ (Register). Use non-sensitive review data and an unused vehicle number. Each account may belong to one vehicle only.
2. Record parking: from Home, tap ‘주차 기록하기’, select floor and zone, optionally enter the parking space number, then ‘주차 기록 저장’ (Save). After server confirmation, view the location on Home and History. Camera/photo-library OCR runs on-device; review and edit its suggestions before saving.
3. Full family-sharing access: on the owner's ‘우리 가족’ (Family) tab, tap ‘가족 초대 코드 만들기’, then copy the code or share the link. On a second device, sign in with a different Apple/Google account. Choose ‘기존 차량 참여 · 초대코드 입력’ (Join an existing vehicle), enter the invitation, and tap ‘가족 차량에 참여하기’. Do not register a separate vehicle for this second account. Invitations are single-use and expire after 24 hours; the owner can create a fresh one. Both accounts can then view the shared parking location and history.
4. Delete the account via ‘설정’ (Settings) → ‘개인정보와 계정’ → ‘계정 삭제’. Deletion also removes the owner's vehicle and its shared records. Apple users reauthenticate to disconnect Apple; an explicit manual-disconnection option is offered if automatic disconnection is unavailable. Please test deletion last.

‘체험 시작하기’ (Try the demo) uses local sample data only. It does not provide real server storage, cross-account sharing, server invitations, or server account deletion. Use the sign-in and invitation flow above to review those features.
