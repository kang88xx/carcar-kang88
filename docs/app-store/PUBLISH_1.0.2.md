# 공개 소개 개선 제출 · 2026-11-13

사용자가 Chrome에서 스크린샷과 문구를 확인한 뒤 진행을 승인했다. **1.0.2 (16)를 심사에 제출했고, Apple의 응답은 `WAITING_FOR_REVIEW`, 차단 항목 0개다.** 출시 방식은 기존과 같은 `AFTER_APPROVAL`이다. 승인·공개 완료와 구분한다.

## 반영한 내용

- iPhone 1320×2868, iPad 2064×2752 JPEG 각 5장: 위젯·아이콘 → 주차 등록 → 홈 → 가족 → 이력.
- 한국어 부제 `아파트 주차 위치, 혼자도 가족과도`와 설명·키워드·홍보문·새 기능 문구. 원고는 `public-listing-ko.json`, 제출용 문서는 `update-1.0.2.json`이다.
- 첫 이미지는 제품 SwiftUI 위젯 렌더와 실제 아이콘을 조합한 보기 예시이며, 실제 홈 화면 촬영이 아니다. 이 사실을 심사 메모에도 명시했다. 나머지는 빌드 15와 같은 화면의 체험 모드 촬영본이다.
- 제품 기능은 그대로이며 `pubspec.yaml`의 버전/빌드와 설정 화면의 버전 문자열만 바꿨다. 가격·국가·개인정보 답변·서버 설정을 바꾸지 않았다. 웹 소개 페이지 수정은 소스 브랜치에 보관했으며 공개 사이트 배포는 이번 제출에 포함하지 않는다.
